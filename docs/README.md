# Kpocha Touch Documentation

Welcome to the Kpocha Touch user documentation hub. This documentation is designed for people who want to understand what the platform does, how to use it, and where to get help.

## Available guides

- `docs/user-guide.md` — A practical guide for clients and general users.
- `docs/professional-guide.md` — Instructions and best practices for professionals offering services.
- `docs/faq.md` — Answers to common questions about booking, payments, profiles, and safety.
- `docs/privacy-policy-template.md` — Standard privacy policy template to adapt for Kpocha Touch.
- `docs/terms-and-conditions-template.md` — Standard platform terms and conditions template.
- `docs/webrtc.md` — Technical notes on the WebRTC call implementation.

## What this platform is

Kpocha Touch is a professional service marketplace for Nigeria that connects clients with verified service providers. The platform supports bookings, secure profiles, in-app payments, wallet management, and protected communication between clients and professionals.

## How to use these docs

- Start with `docs/user-guide.md` if you want to book services or use the platform as a client.
- Read `docs/professional-guide.md` if you are a professional who wants to register, list services, and manage bookings.
- Use `docs/faq.md` if you have quick questions about the product.

> These docs are meant for users and service providers, not developers. For development and deployment notes, see the root `README.md` and `docs/webrtc.md`.
